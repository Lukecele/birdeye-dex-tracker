# Contributing to DEX Swap Tracker & Telegram Bot

We welcome open-source contributions to enhance multi-chain DEX liquidity tracking, alert formatting, and administrative dashboards.

## How to Contribute
1. Fork the repository.
2. Create a feature branch: `git checkout -b feat/your-feature`.
3. Verify that typechecking passes (`npm run lint`), tests pass (`npm test`), and bundling succeeds (`npm run build`).
4. Commit your changes using conventional commit messages.
5. Submit a Pull Request against `main`.
