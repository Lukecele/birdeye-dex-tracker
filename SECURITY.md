# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT open a public GitHub issue.

Please report vulnerabilities directly to:
- **Email:** `security@arbitrage-inc.exchange`
- **Telegram:** [Arbitrage Inception Telegram](https://t.me/ArbitrageInception)

### What to Include
- Detailed description of the potential vulnerability
- Steps to reproduce or payload demonstration
- Evaluation of severity and impact
- Suggested fix (if available)

We acknowledge submissions within 48 hours and coordinate fixes prior to public disclosure.

## Scope
- Daemon webhook endpoints and polling engine (`server.ts`)
- Telegram bot command parsing and notification formatters
- Frontend administration dashboard
